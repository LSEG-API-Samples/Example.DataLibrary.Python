DesktopSession

This type of session is used to connect to the Data Platform through Refinitiv Eikon or LSEG Workspace. It requires Refinitiv Eikon or LSEG Workspace to be running alongside your application. This type of session does not work with Refinitiv Eikon Web or LSEG Workspace for Web.

A desktop session is created with lseg.data.session.desktop.Definition. The session it returns has the members described in Sessions.

Creating a desktop session

lseg.data.session.desktop.Definition defines a desktop session. It can be defined indirectly using the name of a session defined in the configuration file or directly by specifying the app_key parameter.

Definition(name: str = 'workspace', app_key: str = None, app_name: str = None)
Parameter Type Required Default Description
name str No 'workspace' Name of the session in the config file.
app_key str No None Application key.
app_name str No None Application name.

Definition.get_session() creates and returns the session. It returns the desktop session instance.

Raises

Exception When
Exception If app-key is not found in the config file and in arguments.

Example

from lseg.data import session

definition = session.desktop.Definition(name="custom-session-name")
desktop_session = definition.get_session()
