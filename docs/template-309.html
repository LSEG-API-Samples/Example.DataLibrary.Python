Session states and events

A session reports its state through OpenState and its status events through EventCode. Register callbacks with Sessions: on_state and on_event to be notified of changes.

OpenState

Session lifecycle state. Available as lseg.data.OpenState.

Name Value Description
OpenState.Opened 'Opened' The session is open and ready to work.
OpenState.Pending 'Pending' The session is waiting to be opened or closed.
OpenState.Closed 'Closed' The session is closed.

A session's open(), close() and their async versions return an OpenState. The open_state property of a session returns the session state, and on_state callbacks receive an OpenState.

EventCode

Each session can report different status events during its lifecycle. Available as lseg.data.session.EventCode.

Name Value Description
EventCode.StreamConnecting 1 The connection to the stream service within the session is pending.
EventCode.StreamConnected 2 The connection to the stream service has been successfully established.
EventCode.StreamDisconnected 3 The connection to the stream service is not established.
EventCode.StreamAuthenticationSuccess 4 The stream has successfully authenticated this client.
EventCode.StreamAuthenticationFailed 5 The stream has failed to authenticate this client.
EventCode.StreamReconnecting 6
EventCode.SessionConnecting 21
EventCode.SessionConnected 22
EventCode.SessionDisconnected 23
EventCode.SessionAuthenticationSuccess 24 The session has successfully authenticated this client.
EventCode.SessionAuthenticationFailed 25 The session has failed to authenticate this client.
EventCode.SessionReconnecting 26
EventCode.SessionAuthenticationFailedRefreshTokenFailed 27
EventCode.SessionAuthenticationFailedRefreshTokenExpired 28

EventCode.SessionRealTimeAccessAllowed 40
EventCode.SessionRealTimeAccessDenied 41
EventCode.DataRequestOk 61 The request for content from the session data services has completed successfully.

on_event callbacks receive an EventCode.
