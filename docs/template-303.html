DesktopDirectSession

DesktopDirect sessions connect to the Workspace API Gateway using an Entra token exchange.

A DesktopDirect session is created with lseg.data.session.desktopdirect.Definition. The session it returns has the members described in Sessions.

Creating a DesktopDirect session

lseg.data.session.desktopdirect.Definition defines a DesktopDirect session using a named configuration and an optional Entra authentication provider. The app key is read from the configuration.

Definition(
    name: str = 'default',
    entra_provider: EntraAuthentication | EntraAuthenticationProvider = None,
    take_real_time_control: bool = False,
    deployed_platform_host: str = None,
    deployed_platform_username: str = None,
    dacs_position: str = None,
    dacs_application_id: str = None,
)
Parameter Type Required Default Description
name str No 'default' Name of the session in the config file.
entra_provider EntraAuthentication | EntraAuthenticationProvider No None An EntraProvider wrapping a user-supplied token callback, or an EntraAuthentication acquiring tokens with MSAL. A bare callback or raw token is not accepted.
When omitted, the Entra client ID and authority are read from 'sessions.desktop-direct.<name>.entra-client-id'/'entra-authority' in the local config file, with fallback to the default session.
To customize the MSAL scope or redirect port, pass an EntraAuthentication instance with scope or redirect_port set.
take_real_time_control bool No False Whether to request real-time control when exchanging the Entra token.
deployed_platform_host str No None Host name (or IP) and port of a local Real-Time Distribution System. When set, the pricing streaming endpoint (apis.streaming.pricing.endpoints.main) is served by this Real-Time Distribution System, while every other request keeps going through the Workspace API Gateway. The Real-Time Distribution System usually requires the service to be set explicitly, either on the stream definition or with the 'sessions.desktop-direct.<name>.apis.streaming.pricing.service' config parameter.
deployed_platform_username str No None DACS username identifying the user when connecting to the Real-Time Distribution System. Required when deployed_platform_host is set.
dacs_position str No None DACS position identifying the terminal when connecting to the Real-Time Distribution System.
dacs_application_id str No None DACS application ID used when connecting to the Real-Time Distribution System.

Definition.get_session() creates and returns the session. It returns the DesktopDirectSession instance.

Raises

Exception When
Exception If the entra_provider is not valid, or deployed_platform_host is set without deployed_platform_username.

EntraAuthenticationProvider

lseg.data.session.desktopdirect.EntraAuthenticationProvider is Entra authentication using a user-supplied token callback.

EntraAuthenticationProvider(get_access_token: Callable[[], str])
Parameter Type Required Description
get_access_token Callable[[], str] Yes A callback invoked with no arguments whenever the library needs an Entra access token: once when the provider is created, and again automatically whenever Heimdall's own refresh token has expired and can no longer be renewed, so the token-exchange flow can restart with a fresh Entra token instead of leaving the session unauthorized. Must return a non-empty token string. The callback is required; token acquisition and any caching are the caller's responsibility.

EntraAuthentication

lseg.data.session.desktopdirect.EntraAuthentication is MSAL-based Entra authentication for a DesktopDirect session.

EntraAuthentication(
    entra_client_id: str,
    entra_authority: str = None,
    scope: str = None,
    redirect_port: int = None,
)
Parameter Type Required Default Description
entra_client_id str Yes Entra application (client) ID.
entra_authority str No None Entra authority URL. Defaults to https://login.microsoftonline.com/organizations.
scope str No None Entra scope to request instead of <entra_client_id>/.default. Must be a non-empty string when provided.
redirect_port int No None Local redirect port for interactive authentication. When omitted or set to 0, MSAL uses a system-allocated port. Valid values are integers from 0 to 65535. The redirect URI uses http://localhost.

It acquires an Entra token during construction, reusing an encrypted MSAL cache when possible and otherwise using interactive authentication. The same client ID, authority, scope and redirect port are used when the session needs a fresh token to restart its token exchange. It requires the optional dependencies installed with pip install lseg-data[entra].

get_entra_token

lseg.data.session.desktopdirect.get_entra_token acquires an Entra access token using MSAL and an encrypted token cache.

get_entra_token(
    entra_client_id: str,
    authority: str,
    scope: str = None,
    redirect_port: int = None,
) -> str

It tries silent acquisition for a single cached account before opening interactive authentication. Multiple cached accounts are rejected.

On Windows the cache is encrypted with DPAPI and can only be decrypted by the same Windows user. On macOS it is stored in Keychain, and on Linux it is stored through Secret Service/libsecret.

msal and msal-extensions are optional dependencies imported lazily on first call. Install them with pip install lseg-data[entra] (or pip install msal msal-extensions) before calling this function.

Parameter Type Required Default Description
entra_client_id str Yes Entra application (client) ID.
authority str Yes Entra authority URL, for example https://login.microsoftonline.com/organizations.
scope str No None Entra scope to request. Defaults to <entra_client_id>/.default. Must be a non-empty string when provided; surrounding whitespace is stripped.
redirect_port int No None Local redirect port for interactive authentication. When omitted or set to 0, MSAL selects an available port. Valid values are integers from 0 to 65535. Passed as port to MSAL's interactive acquisition; silent acquisition does not use it.

Returns

str: the acquired Entra access token.

Raises

Exception When
LDError If the client ID or authority is missing, or scope or redirect_port is invalid.
RuntimeError If an optional MSAL dependency is missing, encrypted caching is unsupported, multiple cached accounts are found, or token acquisition returns no access token.

Example

Wrap your own no-argument token acquisition function, get_token:

from lseg.data import session

definition = session.desktopdirect.Definition(
    entra_provider=session.desktopdirect.EntraAuthenticationProvider(get_access_token=get_token),
)
definition = session.desktopdirect.Definition(
    entra_provider=session.desktopdirect.EntraAuthentication(
        entra_client_id="<your-entra-client-id>",
        entra_authority="https://login.microsoftonline.com/organizations",
        scope="api://<resource-id>/.default",
        redirect_port=8400,
    ),
)
desktop_direct_session = definition.get_session()
