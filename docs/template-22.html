open_pricing_stream

Creates and opens a pricing stream.

open_pricing_stream is part of the Access layer. Import the library as import lseg.data as ld and call ld.open_pricing_stream(...). A session must be open first.

Syntax

open_pricing_stream(
    universe: str | Iterable[str],
    fields: str | list[str] = None,
    service: str | None = None,
    on_data: Callable | None = None,
) -> PricingStream

Parameters

Parameter Type Required Default Description
universe str | Iterable[str] Yes Instruments to request.
fields str | list[str] No None Fields to request.
service str | None No None Name of the streaming service publishing the instruments.
on_data Callable | None No None Callback function.

Returns

PricingStream; see PricingStream.

Raises

Exception When
ValueError The default session is not open: Session is not opened. Can't send any request

Example

import lseg.data as ld


def callback(updated_data, ric, stream):
    print(updated_data)


pricing_stream = ld.open_pricing_stream(
    universe=['EUR='],
    fields=['BID', 'ASK', 'OPEN_PRC'],
    on_data=callback,
)
