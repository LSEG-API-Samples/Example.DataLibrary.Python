get_data

Retrieves pricing snapshots, as well as Fundamental and Reference data.

get_data is part of the Access layer. Import the library as import lseg.data as ld and call ld.get_data(...). A session must be open first.

Syntax

get_data(
    universe: str | Iterable[str],
    fields: str | Iterable[str],
    parameters: str | dict | None = None,
    header_type: HeaderType = HeaderType.TITLE,
) -> DataFrame

Parameters

Parameter Type Required Default Description
universe str | Iterable[str] Yes Instruments to request
fields str | Iterable[str] Yes Fields to request
parameters str | dict | None No None Single key=value global parameter or dictionary of global parameters to request
header_type HeaderType No HeaderType.TITLE If HeaderType.TITLE - returns field title as column headers for data
If HeaderType.NAME - returns field name as column headers for data
If HeaderType.NAME_AND_TITLE - returns field name and title as column headers for data

Returns

pandas.DataFrame

Raises

Exception When
ValueError The default session is not open: Session is not opened. Can't send any request

Example

Open a session, retrieve data, close the session:

import lseg.data as ld

ld.open_session()

df = ld.get_data(universe=['IBM.N', 'VOD.L'], fields=['BID', 'ASK'])
print(df)

ld.close_session()

Retrieve fundamental data with global parameters:

df = ld.get_data(
    universe=['GOOG.O', 'AAPL.O'],
    fields=['TR.EV', 'TR.EVToSales'],
    parameters={'SDate': '0CY', 'Curn': 'CAD'},
)

HeaderType

HeaderType is the type of the column headers returned for data. It is available as lseg.data.HeaderType.

Name Value Meaning
HeaderType.NAME 1 field name as column header.
HeaderType.TITLE 2 field title as column header.
HeaderType.NAME_AND_TITLE 3 field name and title as column header.
