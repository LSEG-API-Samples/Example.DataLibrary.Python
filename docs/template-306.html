open_session and close_session

open_session opens and returns a session. close_session closes the previously opened session.

Import the library as import lseg.data as ld and call ld.open_session(...) and ld.close_session().

open_session

Opens and returns a session.

open_session(
    name: str | None = None,
    app_key: str | None = None,
    config_name: str | None = None,
) -> Session
Parameter Type Required Default Description
name str | None No None Session name from the config file.
app_key str | None No None The application key.
config_name str | None No None The config name. If provided, overrides default config.

Returns: Session. The session has the members described in Sessions.

close_session

Closes the previously opened session.

close_session() -> None

Returns: None

Example

import lseg.data as ld

ld.open_session()

# ... use the library, for example ld.get_data(...)

ld.close_session()
