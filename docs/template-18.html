get_history

Retrieves the pricing history, as well as Fundamental and Reference data history.

get_history is part of the Access layer. Import the library as import lseg.data as ld and call ld.get_history(...). A session must be open first.

Syntax

get_history(
    universe: str | Iterable[str],
    fields: str | Iterable[str] | None = None,
    interval: str | None = None,
    start: OptDateTime = None,
    end: OptDateTime = None,
    adjustments: str | None = None,
    count: int | None = None,
    parameters: str | dict | None = None,
    header_type: HeaderType = HeaderType.TITLE,
) -> DataFrame

Parameters

Parameter Type Required Default Description
universe str | Iterable[str] Yes Instruments to request
fields str | Iterable[str] | None No None Fields to request
interval str | None No None Date interval. Supported intervals are: tick, tas, taq, minute, 1min, 5min, 10min, 30min, 60min, hourly, 1h, daily, 1d, 1D, 7D, 7d, weekly, 1W, monthly, 1M, quarterly, 3M, 6M, yearly, 1Y
start str | date | datetime | timedelta | None No None The start date and timestamp of the requested history
end str | date | datetime | timedelta | None No None The end date and timestamp of the requested history
adjustments str | None No None Tells the system whether to apply or not apply CORAX (Corporate Actions) events or exchange/manual corrections or price and volume adjustment according to trade/quote qualifier summarization actions to historical time series data. Possible values are: exchangeCorrection, manualCorrection, CCH, CRE, RTS, RPO, unadjusted, qualifiers
count int | None No None The maximum number of data points returned. Values range: 1 - 10000. Applies only to pricing fields.
parameters str | dict | None No None Single global parameter key=value or dictionary of global parameters to request. Applies only to TR fields.
header_type HeaderType No HeaderType.TITLE If HeaderType.TITLE - returns field title as column headers for data
If HeaderType.NAME - returns field name as column headers for data
If HeaderType.NAME_AND_TITLE - returns field name and title as column headers for data

HeaderType is described on the get_data page.

Returns

pandas.DataFrame

Raises

Exception When
ValueError The default session is not open: Session is not opened. Can't send any request

Example

import lseg.data as ld

ld.open_session()

df = ld.get_history(universe="GOOG.O")

df = ld.get_history(universe="GOOG.O", fields="tr.Revenue", interval="1Y")

df = ld.get_history(
    universe="GOOG.O",
    fields=["BID", "ASK", "tr.Revenue"],
    interval="1Y",
    start="2015-01-01",
    end="2020-10-01",
)
print(df)

ld.close_session()
