Configuration

load_config loads the user's config file and sets this file as default. get_config gets the library configuration.

Import the library as import lseg.data as ld and call ld.load_config(...) and ld.get_config().

load_config

Load user's config file and set this file as default.

load_config(path: str | None) -> _RDPConfig
Parameter Type Required Description
path str | None Yes Path to user's config file.

Returns: config object

Exception When
Exception If can't find file by path that user provided

get_config

Gets the library configuration. The configuration is loaded from the configuration files on first use.

get_config() -> _RDPConfig

Returns: config object. Current configuration.
